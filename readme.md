## membuat webiste company profile dengan node js(express js framework)

**Inisialisasi Project**

Jalankan: `npm init -y`

**Install Express**
Sekarang install framework-nya: `npm install express`

Install sebagai dependency pengembangan:`npm install --save-dev nodemon`

`npm install ejs` -> view menggunakan ejs

`npm install express-ejs-layouts` -> untuk layout

`npm install express-validator` -> form validation
